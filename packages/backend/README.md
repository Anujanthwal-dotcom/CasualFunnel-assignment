# @casualfunnel/backend

NestJS ingestion + aggregation API for CausalFunnel analytics. Persists events in MongoDB and aggregates them on demand for sessions, timelines, heatmaps, pages, and stats. Also serves the compiled tracker bundle and a WebSocket feed for live updates. See the [root README](../../README.md) for the full architecture, API reference, and setup.

## Run

```bash
cp .env.example .env
npm install            # from the repo root — this is an npm workspace
npm run dev -w @casualfunnel/backend
```

The API listens on `:3000` with a global `/api` prefix:

| Endpoint                         | Purpose                              |
| -------------------------------- | ------------------------------------ |
| `POST /api/events`               | Ingest events                        |
| `GET  /api/sessions`             | Session list (aggregated on demand)  |
| `GET  /api/sessions/:id/timeline`| One session's ordered events         |
| `GET  /api/heatmap`              | Click coordinates for a page         |
| `GET  /api/pages`                | Distinct tracked pages               |
| `GET  /api/stats`                | Global counters                      |
| `GET  /api/health`               | Liveness + MongoDB readiness         |
| `GET  /api/docs`                 | Swagger UI                           |
| `GET  /tracker.js`               | Compiled tracker bundle (static)     |

## Scripts

```bash
npm run dev          # nest start --watch
npm run build        # nest build → dist/
npm run start:prod   # node dist/main.js
npm run seed         # insert sample sessions/events
npm test             # unit tests (Vitest)
npm run test:e2e     # e2e tests (requires MongoDB)
npm run lint
```

## Environment

Copy `.env.example` to `.env`; the defaults work out of the box.

| Variable | Default | Purpose |
| --- | --- | --- |
| `PORT` | `3000` | HTTP port |
| `NODE_ENV` | `development` | Node environment |
| `MONGODB_URI` | `mongodb://localhost:27017/casualfunnel` | MongoDB connection string |
| `CORS_ORIGINS` | `*` | Comma-separated allowed origins, or `*` |
| `API_KEY` | *(empty)* | When set, `POST /api/events` requires `x-api-key` |
| `HEATMAP_MAX_POINTS` | `20000` | Cap on click points returned per heatmap query |
| `THROTTLE_TTL_MS` | `60000` | Rate-limit window |
| `THROTTLE_LIMIT` | `5000` | Requests per window per IP |
| `SEED_SESSIONS` | `18` | Sessions generated by `npm run seed` |

## Structure

- `src/events/` — ingestion: schema, DTOs, `IngestPipe`, service, WebSocket gateway
- `src/sessions/` — session list (`$facet`) + per-session timeline
- `src/heatmap/` — click coordinates + viewport bounds
- `src/pages/` — distinct page URLs with counts
- `src/stats/` — global counters
- `src/health/` — liveness + MongoDB readiness
- `src/common/guards/` — optional `x-api-key` guard
- `src/seed.ts` — sample-data seeder
- `src/main.ts` — CORS, global `/api` prefix, static `/tracker.js`, Swagger
